# 50 母题经验预测与 GBDT：训练 v2 Review

2026-10-31。已完成四轮数据合并、固定 5 折母题分组评测、全开发集重拟合及保存加载核验。**本轮条件经验基线整体仍优于固定强正则 GBDT；已等待至少 1 秒的快照中，GBDT 较好。** 结果是开发集折外诊断，尚无独立来源/时间测试或在线 KV 收益实验。

这里的“训练 v2”指扩量后的第二轮对照，区别于“修复数据 v2”。它沿用旧 [GBDT Review 2](gbdt_review_2.md) 的模型输入及参数，更新数据和母题划分；新增强字段用于分层评测，尚未作为预测输入。

## 整体结果

指标为各窗口累计 `[F_U, F_D, S]` 的三类 Brier 分数：平方误差之和，范围 0–2，越低越好，不是百分比准确率。先在执行内按快照权重平均，再在母题内平均执行，最后各母题等权；主指标预先固定为 **0.1 秒的母题宏平均 Brier**。

| 数据范围 / 预测窗口 | 全局经验 | 条件经验 | GBDT |
|---|---:|---:|---:|
| 完整集 / **0.1 秒，主指标** | 0.4986 | **0.3889** | 0.4317 |
| 完整集 / 1 秒 | 0.3291 | **0.2917** | 0.3084 |
| 完整集 / 3 秒 | 0.3063 | **0.2696** | 0.2879 |
| 完整集 / 10 秒 | 0.2939 | **0.2565** | 0.2762 |
| 质量子集 / **0.1 秒，主指标** | 0.5124 | **0.4027** | 0.4440 |
| 质量子集 / 1 秒 | 0.3465 | **0.3043** | 0.3247 |
| 质量子集 / 3 秒 | 0.3222 | **0.2801** | 0.3027 |
| 质量子集 / 10 秒，仅有支持的留出组 | 0.3170 | **0.2722** | 0.2973 |

完整集 0.01–10 秒各窗口覆盖全部 2,414 张快照。质量子集 0.01–3 秒覆盖全部 1,553 张；10 秒仅覆盖 **1,037 张、37 个母题**，另 516 张、10 个母题的训练折缺少对应风险集，三种模型一起排除，不能将这行视为完整质量子集上的分数。30 秒及之后全部无支持，概率保持 null。

条件风险行 NLL 同样越低越好；它是区间条件对数损失，使用 `1e-15` 概率下限，不是整条生存路径似然：

| 数据范围 | 全局经验 | 条件经验 | GBDT |
|---|---:|---:|---:|
| 完整集 | 0.7446 | **0.4137** | 0.6540 |
| 质量子集 | 0.8319 | **0.4936** | 0.6710 |

0.1 秒 GBDT 相对条件经验的 Brier 差值为完整集 **+0.04271**、质量子集 **+0.04127**。完整集 50 个母题均是条件经验更低；质量子集为 45 个条件经验更低、2 个 GBDT 更低。预先固定的 2,000 次配对母题重采样给出的描述性 95% 区间分别为 `[0.03859, 0.04651]`、`[0.03619, 0.04573]`。这些折共享训练数据，区间不应解释为独立测试集上的显著性结论。

相较旧十题实验，数据分布、时长和折划分均已改变，不能仅凭新旧主指标差异宣称扩量提高或降低了泛化能力。同一新数据和同一划分上的模型对照才是本轮结论。

## 秒级和重试状态

以下仍为同一批折外预测，没有在子集上重新训练。表中均为 **0.1 秒累计 Brier**。

| 范围 / 分层 | 快照 / 母题 | 条件经验 | GBDT |
|---|---:|---:|---:|
| 完整集 / 当前已等待 ≥1 秒 | 126 / 6 | 0.4877 | **0.3930** |
| 质量子集 / 当前已等待 ≥1 秒 | 95 / 6 | 0.5879 | **0.4109** |
| 完整集 / 最终 episode <1 秒 | 2,168 / 50 | **0.3789** | 0.4243 |
| 完整集 / 最终 episode 1–3 秒 | 58 / 6 | 0.6642 | **0.6424** |
| 完整集 / 最终 episode 3–10 秒 | 188 / 3 | 0.7227 | **0.6659** |
| 质量子集 / 最终 episode 3–10 秒 | 136 / 2 | 0.8792 | **0.7219** |

“已等待 ≥1 秒”是预测时已知的状态；最终 episode 时长是会话结束后的分层条件，**仅用于评测，不传给模型**。最终时长分层与预测剩余时间窗口不是同一个量。GBDT 在秒级状态有改善迹象，但误差仍高，且独立母题少，不足以认定已经可靠掌握长工具分布。

补充覆盖检查发现：所有设计文件母题落在第 3/4 折。质量子集唯一供应 `(3,10]` 风险行的 CSV、图两个母题恰好都在第 3 折；将它们留出后，该折训练集没有此区间的风险行，所以其 516 张验证快照在 10 秒无支持。保留预定的哈希划分，没有根据结果重新分配。完整集的 JSONL 失败执行仍提供第三个长时段母题，因此完整集各折都有支持；这不表示质量失败执行能替代长时段合格数据扩充。

分层文件另报告采集轮次、当前已观察失败、显式重试及执行最终质量。旧 MBPP 未采到的失败历史保持 unknown，没有补成 0；v2 的当前重试标记来自原 sidecar。该标记本轮只参与分层，不能将条件经验/GBDT 的分数差异归因于模型已使用重试特征。

## 数据与固定协议

| 视图 | 母题 | 执行 | episode | 快照 | 风险行 | U / D / 自然 C |
|---|---:|---:|---:|---:|---:|---|
| all-observed，主集 | 50 | 65 | 472 | 2,414 | 7,051 | 407 / 65 / 0 |
| qualified，质量子集 | 47 | 54 | 296 | 1,553 | 4,560 | 242 / 54 / 0 |

输入来自固定 [50 母题清单](../results/prediction/dataset_inventory_50parents_2026-10-31.json)，包含旧 MBPP、文件 v1、修复 v2、母题 v3；旧 HTTP 400 执行继续隔离。合并器核对 57 个输入路径的哈希、母题映射、sidecar/base 对齐、开放 episode、时间起点、样本与 target 身份及子集关系。原始数据目录保持原版本，未拼接共享 raw journal。

源快照权重在每个 episode 内合计 1，合并后除以该执行的 episode 数，使每个 workflow 的**快照**权重合计 1。风险行继承快照权重，尚未结束的快照会展开多个风险区间，风险行总权重不要求每个 workflow 仍为 1。

母题组直接使用审计清单的 `group_id`。同一 MBPP 的贪心/采样、文件原任务及修复中/大规模始终同组；按 `SHA256(seed:group)` 排序后轮流分入 5 折，seed=23。完整集每折留出 10 个母题，质量子集沿用相同映射，各折留出 9–10 个。三个模型、两种视图共享这套划分。只有训练折拟合词表、经验计数和树；每张快照恰好得到一份留出母题预测。

最小九字段通过现有白名单校验；实际学习输入沿用旧对照的 `tool_name`、`phase`、`elapsed_idle_s` 桶以及风险区间序号，兼容身份用于支持性校验。elapsed 桶边界仍为 `.03,.1,.3,1`，因此 ≥1 秒均在同一 elapsed 桶。工具名称主要是 bash，新增命令类别、工作量、历史失败和当前重试尚未作为模型特征。这是同输入的扩量复跑。

全局经验按区间汇总 U/D/waiting 权重；条件经验按 tool/phase/elapsed 桶分别估计，每组至少 3 条风险执行、以权重 1 的全局先验收缩。GBDT 为单个共享 LightGBM 三分类模型：40 轮、学习率 0.05、深度 2、最多 4 叶、最小叶样本 20、L1=0.1、L2=10；两个全量重拟合均产生 120 棵树，最大 4 叶。没有参数搜索、提前停止、事后校准或按结果修改配置。

当前结果支持继续保留条件经验基线作为主要对照。粗输入与固定强正则可能限制树模型表达，但本轮没有深度、正则或增强特征对照，不能据此确定唯一原因。下一部分宜预先固定增强特征消融方案，并增加独立的秒级母题覆盖；不应仅靠重复短任务或事后调参追求超过基线。

## 产物、复现与验证

配置为 [prediction_v2_50parents.json](../configs/prediction/prediction_v2_50parents.json)。在已恢复清单对应数据、安装 prediction/test 依赖的本机环境中，可使用新目录复跑：

```bash
.venv/bin/python scripts/train_prediction_v2.py \
  --output .artifacts/prediction/prediction_v2_50parents_replay \
  --summary-output results/prediction/prediction_v2_50parents_replay
.venv/bin/python scripts/verify_prediction_v2.py \
  --results results/prediction/prediction_v2_50parents_replay
```

| 路径 | 内容 |
|---|---|
| `.artifacts/prediction/prediction_v2_50parents/merged/<view>/` | workflow 权重快照、targets、episode 标签及独立的评测元数据 |
| `.artifacts/prediction/prediction_v2_50parents/*-fold-*-*.json` | 30 份折内模型 |
| `.artifacts/prediction/prediction_v2_50parents/*-oof-predictions.jsonl` | 完整集和子集的折外区间/累计概率 |
| `.artifacts/prediction/prediction_v2_50parents/source/` | 训练前冻结源码 |
| `results/prediction/prediction_v2_50parents/` | 6 份全开发集重拟合模型、指标、划分、来源、示例与验证 |

模型输出各区间 `hU/hD/h0`，并递推累计 `F_U/F_D/S`。评测读取折内留出预测；结果目录中的全量重拟合模型不用于宣称折外分数。完整输出例子见 [prediction-examples](../results/prediction/prediction_v2_50parents/prediction-examples.json)，含当前已等待 ≥5 秒及真实重试状态的快照。

独立 [verification](../results/prediction/prediction_v2_50parents/verification.json) 已逐一加载 30 份折内模型，重建训练折的经验计数/GBDT 支持表，复播 **11,901 份模型分布**（3,967 张主集/子集快照 ×3 模型），与保存的 OOF 输出完全一致；重新计算的完整指标一致，概率归一、累计递推、保存加载、分组隔离和历史结果哈希均通过。主集与子集有重叠，这些不是 3,967 个独立 episode。

回归 **121 项通过**，其中合并/分组及原预测器定向测试 18 项通过。环境为 Python 3.12.0、LightGBM 4.6.0、NumPy 2.5.4、SciPy 1.18.1、aarch64。完整集 GBDT API 预测中位数约 0.517 ms，条件经验约 0.075 ms；为本机描述性调用测量，不含状态采集、调度和在线集成开销。

本轮保留全部历史数据和旧模型，不接入在线缓存策略。44/50 母题来自公开 MBPP，长工具仅由少数设计任务提供，质量子集有成功筛选偏差，仍无自然 C、≥10 秒 episode、并发依赖或独立来源测试。详细指标见 [metrics](../results/prediction/prediction_v2_50parents/metrics.json)、[分层指标](../results/prediction/prediction_v2_50parents/stratified-metrics.json)、[汇总](../results/prediction/prediction_v2_50parents/summary.json)。
